# رفع عربيتي — 15 نوفمبر 2026

الملف: `3arabity-app-2026-11-15.zip` (نفس شكل `3arabity-app.zip` اللي فات: تطبيق Node واحد فيه الـ API والموقع في `public/` ولوحة الأدمن في `public/admin/`).

## الخطوات
1. خد نسخة احتياطية من الملفات اللي على السيرفر دلوقتي (أو سيب `3arabity-app.zip` القديم جنبك).
2. ارفع محتوى الـ zip الجديد مكان القديم. **متمسحش ملف `.env`** ولا فولدر `uploads/` لو موجودين على السيرفر.
3. نفّذ `npm install --omit=dev` (فيه مكتبة جديدة: `@anthropic-ai/sdk`).
4. أعد تشغيل التطبيق (Start/Restart من لوحة Hostinger)، أمر التشغيل زي ما هو: `npm start`.

## في `.env` على السيرفر
- مفيش حاجة لازم تتغير.
- اختياري: `ANTHROPIC_API_KEY=...` عشان Claude يقرا كروت المحلات ويشغّل مساعد الأسئلة (فقاعة "عندك سؤال؟"، حوالي ٠.٠١ دولار للسؤال). من غيره قراءة الكروت بتشتغل مجاناً جوه موبايل المحل، والمساعد مش بيظهر.

## اتأكد بعد الرفع
- `https://3rbyty.com/api/v1/health` بيرجع `"database":"up"`.
- الرئيسية على الموبايل بتفتح، وصفحة قطعة، و`/admin`.
- اعمل حساب محل تجريبي أو بيع قطعة بـ "كل الموديلات" وامسحها بعد كده.

## لو حصلت مشكلة
ارجع للـ zip القديم `3arabity-app.zip` بنفس الخطوات.

## إزاي يتعمل الملف ده تاني
```
cd backend && npm run build
cd ../front && npm run build
cd ../admin && npm run build
cd .. && node deploy/make-package.mjs
```
وبعدين اضغط فولدر `deploy/3arabity-app` zip.
